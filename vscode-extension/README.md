# m-eq Math Autocomplete (VS Code)

DISCLAIMER: This extension was completely generated by AI.

Autocomplete, parameter hints and hover docs for `<m-eq>` / `<m-eqi>` equations
from HTMLMathRenderer. Everything only activates **inside** an `<m-eq>` element.

- Type `\` for completions (`\alpha`, `\frac{num}{den}`, aliases like `\a`...)
- Accepting a function like `\attach` opens the parameter popup; the current
  field is highlighted (`{bottom-right}`...) with its docs. `Ctrl+Shift+Space`
  re-opens it, and it follows the cursor / Tab.
- Hover over a `\command` to see its glyph and docs
- Snippets: `meq` -> `<m-eq></m-eq>`, `meqi` -> `<m-eqi></m-eqi>`
- **Live preview**: renders the equation your cursor is in, in a side panel (see below)

## Layout

    HTMLMathRenderer/
      src/constants.js
      dist/math-eq.min.js        used by the preview
      vscode-extension/          <- this folder
        generate-commands.mjs    builds / updates commands.json from src/constants.js
        commands.json            the command table (edit docs here, they are never overwritten)
        extension.js, preview.js, lib.js   the extension
        package.json, snippets.json

## Try it (no install)

From the HTMLMathRenderer folder:

    code --extensionDevelopmentPath="./vscode-extension" .

That opens a VS Code window with the extension loaded. Open `index.html` and type
`\` inside an `<m-eq>`.

(Alternative: open the `vscode-extension` folder itself in VS Code and press F5.)

## Live preview

Open an HTML/Markdown file, then either click the preview icon in the editor's
top-right corner, or run **m-eq: Open Preview to the Side** from the command palette
(`Ctrl+Shift+P`). Click or type inside any `<m-eq>` / `<m-eqi>` and the panel shows
that equation, rendered by your real library. `A-` / `A+` change the zoom. When the
cursor leaves the equation, the last one stays visible (dimmed).

- The preview uses **the same library your page loads**: it reads the document's own
  `<script src="...math-eq...">` (a CDN URL, or a relative / root-relative path to a
  local copy). Switching to a file that loads a different version reloads the panel
  with that version. Hover the panel's status line to see which library is in use.
- If the document has no such tag (or the local file is missing), it falls back to
  `../dist/math-eq.min.js` (when this folder sits inside the repo), then
  `<workspace>/dist/math-eq.min.js`, then the latest build from jsDelivr.
- The `mathEq.previewLibrary` setting (a path or an https URL) overrides all of the above.
- When the repo's `dist/` is used, rebuild the bundle after changing `src/` to see the change.
- KaTeX's font is loaded from jsDelivr, same as on a normal page, so you need
  internet for the exact look. Offline, the preview still works with a fallback font.
- Images with relative paths (like ./testimg.png) show up if the file is inside the
  workspace folder you opened.

## Install permanently

    cd vscode-extension
    npm run package
    code --install-extension math-eq-autocomplete-0.2.1.vsix

Then reload VS Code. After changing `commands.json` or the code, repackage and
reinstall (bump `version` in package.json, or add `--force` to install).

## Updating commands

    node vscode-extension/generate-commands.mjs            # add new commands from constants.js
    node vscode-extension/generate-commands.mjs --dry-run  # just show what would be added

Existing entries are never changed. The extension watches `commands.json` and
reloads it by itself when run via `--extensionDevelopmentPath`; otherwise use the
command palette: **m-eq: Reload commands.json**.

## commands.json format

    { "name": "attach", "aliases": [], "glyph": "(optional, shown in the dropdown)",
      "snippet": "\\attach{$1}{$2}{$3}{$4}{$5}{$6}{$7}",
      "doc": "markdown shown in the popup",
      "params": [ { "label": "main", "doc": "..." }, ... ] }

Only `name` is required. `params` powers the "which field am I in" popup.

## Notes for people installing it from the .vsix

It works in any project, no repo needed: completions, parameter hints, hover and
snippets work in any HTML/Markdown file, and the preview follows the page's script
tag. The command list is bundled at the version the extension was built from, so if
a page uses an older / newer library you may see a command that version lacks (or
miss a new one). Regenerate `commands.json` and repackage when the library changes.

## Settings

- `mathEq.languages` (default `["html", "markdown"]`): language IDs where it works,
  e.g. add `"javascript"` or `"vue"` if you write `<m-eq>` inside template strings.
- `mathEq.previewLibrary` (default empty = auto-detect): where the preview loads
  `math-eq.min.js` from.
